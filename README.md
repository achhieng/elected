# Elected ✓ — New Zealand 1993

A campaign and election-night game set in the 1993 New Zealand general election.

## Publish with GitHub Pages

1. Upload `index.html`, `404.html` and `.nojekyll` to the root of a public repository.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**, branch **main**, folder **/ (root)**.
3. Open `https://<your-user>.github.io/<repo>/`.

You can also just open `index.html` in a browser. Saves are kept in your browser.
